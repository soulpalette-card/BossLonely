# 天道观察者 · 青云宗 ☯

一款**修仙宗门放置游戏**。你不是掌门，也不是弟子——你扮演**天道**。唯一能做的事，是**向宗门投放弟子**，然后袖手旁观：你送来的每一个人，会在青云宗的岁月里自己修炼、结缘、突破、老去、谢幕。宗门的兴衰史，就是你历年投放的弟子们的合传。

> 故事从一个**不足五十人的弱势宗门**开始。三百年前，青云宗曾是云泽郡第一大宗；一场「墨渊之乱」后，九峰陷六、千人星散，如今龟缩主峰、群狼环伺。你投放的弟子，将亲手把它重新养大——或看它彻底覆灭。

## 玩法

- **投放弟子（唯一操作）**：五步捏人——取名 → 选出身（12 模板）→ 选灵根（五行 1–5 种）→ 分配 100 点潜力预算（六维属性）→ 确认投放。落子无悔。
- **三层数值**：你买的是**潜力值**（仅天道可见）；投放瞬间 roll 出无人可见的**实际值**；宗门测灵根得到带误差的**检测值**并据此定级分岗。三者不等，落差即故事——「明珠蒙尘」会自然发生。
- **逐年模拟**：现实 1 小时 ＝ 游戏 1 年（可暂停 / 观流年 / 快进 / 手动推演一年）。每年每个角色都走一遍年度循环：修炼、事件、关系演化、突破判定、寿命判定。关掉页面也在流逝（离线结算，上限 720 年）。
- **读年报**：宗门大事 + 你的弟子这几年的动向 + 讣闻。年报会随宗门壮大而**逐渐变冷**——这本身就是叙事。
- **观兴衰**：宗门分五阶段（风雨飘摇 → 站稳脚跟 → 中兴 → 崛起 → 鼎盛），每阶段由硬指标 + **里程碑大考**把门。大考可胜可败，**输了走衰亡分支**，宗门甚至可能覆灭并生成《亡宗史》。祖制「九殿一阁」随成长逐座点亮。
- **不能干预**：不能给弟子资源、不能救人、不能替宗门做决定。天道只负责创造与记录。功德（软货币）也只扩展「创造端」（如提升捏人预算），永不触碰弟子命运。

## 特色

- 开局 13 名具名 NPC（掌门玄诚子、丹医胡青囊、执法厉秋霜、老魏……）全程活角色，会突破、会老去、会谢幕。
- 弱宗温情：人少时全员被看见，掌门亲测灵根、误差极小、几乎不会被忽视——这份温情会随宗门变大而消逝。
- 关系系统：挚友 / 仇怨 / 师徒 / 道侣 / 引路人 / 眼中钉；你投放的弟子之间相遇结缘，权重最高。
- 传记馆与史书：逝者、离宗者、飞升者自动立传；跨代大事写满史书。

## 运行

纯单文件、零依赖、免安装、免编译——**直接用浏览器打开 `index.html` 即可**。进度自动保存在本地浏览器（localStorage），设置页可导出 / 导入存档、重开新纪元。

## 技术

- 单个 `index.html`，内联 CSS + 原生 JavaScript，`setInterval` 驱动逐年模拟主循环。
- 国潮 / 水墨修仙视觉：墨黑宣纸底、描金标题印章、玉青点缀、朱砂红标记，纯 CSS 无外部资源。
- 数值层与文案层分离：结构化模板掷骰产出事件，文案层填充年报。
