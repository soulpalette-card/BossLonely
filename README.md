# 末日方舟 · 废土求生 🧟

一款浏览器上的 **2D 俯视角末世生存游戏**，玩法灵感取自《方舟：生存进化》。大灾变后，你在废土中醒来——**搜刮、制作、筑墙、结伴**，熬过每一个丧尸横行的夜晚，成为废土的幸存者。

> 搜刮废料 → 打造枪械 → 研究科技 → 建造据点 → 死守血月尸潮

## 玩法

- **生存数值**：体力(HP)、饥饿、口渴、耐力四条状态条随时间变化。饥饿/口渴归零后持续掉血；喝水、进食可恢复，数值充足时缓慢回血。
- **搜刮废料**：靠近 🌲枯树 / 🥀朽木 / 🧱瓦砾堆 / 🚗废弃车 / 🗑️垃圾堆 / 📦补给箱，按「搜刮」收集木料、碎石、布条、罐头、废铁。搜刮点会随时间刷新。
- **合成制作**：用废料打造 🪓消防斧、⛏️撬镐（对口工具搜刮速度 ×3）、🔪砍刀、🔦手电、🪚电锯、💊医疗包，以及靠 🔥火堆 烤 🍖熟肉。
- **🔫 枪械 & 远程战斗**：解锁火器科技后合成 🔫手枪 / 🔫步枪 与 🧨弹药，装备后「射击」自动瞄准最近目标远程开火，子弹飞行命中，可远距离清怪。
- **🔬 科技解锁树**：研究点来自「击杀敌人 / 每日存活(+5) / 挺过尸潮夜(+25)」，用于解锁 8 项科技——照明工程、高效搜刮(产出+50%)、战地医疗、动力刃具、防护装甲(减伤35%)、火器制造、步枪工艺、自动防御(哨戒炮)。
- **🩸 血月尸潮 / Boss 波次**：**第 3 天起每 3 天一场血月**，傍晚降临、持续整夜。丧尸成群从四面涌向你，中途刷新 👹丧尸暴君 Boss（240 血、高伤、掉落弹药与废铁）。挺过一夜奖励 +25🔬。
- **建造据点**：搭建 🧱铁皮墙 / 🚪铁门 挡住丧尸，🔥火堆烹饪照明，💡照明灯固定照明，🔫哨戒炮自动射击来犯丧尸，🛏️睡袋设为重生点。
- **结伴同行**：反复用 🥫罐头喂食 🐀变异鼠 / 🐕流浪狗 / 🐗变异野猪 即可驯服，同伴会跟随你并自动攻击丧尸。
- **昼夜循环**：一整天约 8 分钟。夜晚变暗、丧尸更多更强，需要照明与围墙防守。
- **战斗与死亡**：倒下后在睡袋（或初始地）重生，会损失部分物资。

## 操作

| | 电脑 | 手机 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 左侧摇杆 |
| 搜刮 / 攻击 / 射击 | `空格` | 右下动作按钮 |
| 进食 | `E` | 🍖 按钮 |
| 喝水 | `Q` | 💧 按钮 |
| 切换装备（含枪械） | `1`~`6` | 底部快捷栏 |
| 背包/合成/建造/科技/同伴/设置 | 右上菜单按钮 | 右上菜单按钮 |

## 运行

纯单文件、零依赖、免安装、免编译 —— **直接用浏览器打开 `index.html` 即可游玩**。进度自动保存在本地浏览器（localStorage），设置页可导出/导入存档。

## 技术

- 单个 `index.html`，内联 CSS + 原生 JavaScript，Canvas 2D 渲染，`requestAnimationFrame` 驱动主循环。
- 俯视角 tile 废土地图，实体按 y 轴排序实现伪 3D 叠放；动态昼夜光照（`destination-out` 挖光 + `lighter` 暖色叠加）。
- 搜刮/合成/建造/科技树/枪械弹道/尸潮波次/驯服/存档等系统全部内置，emoji 作为美术资源，无任何外部依赖。
