# 寂寞老板修仙传 🏮

一款用**现代职场**演绎经典修仙的**挂机放置**小游戏。老板从摆摊创业起步，招贤纳士、组建上市天团，一路打项目、渡商劫，最终**敲钟上市**、飞升商界传奇。

> 灵石 → 现金 · 修士收徒 → 聘请员工 · 妖魔鬼怪 → 项目 · 渡劫飞升 → IPO 上市 · 转生轮回 → 二次创业

## 玩法

- **挂机收益**：在职员工每秒被动产出现金，关掉页面也在赚（离线收益结算，上限可升级）。
- **打项目（打怪）**：全体员工自动攻击当前项目，击破即通关、进入下一关；每 10 关是「大项目 Boss」，限时未破则项目重置。点击项目还能**亲自督战**造成额外伤害。
- **聘请与培养**：花现金聘请 10 类员工（实习生 → 前台 → 销售 → 程序员 → 设计师 → 产品经理 → 运营总监 → CTO → CFO → 天才黑客），数量达 10/25/50/100… 名时该职位产出与战力**翻倍**。高品阶员工需晋升境界后解锁。
- **境界突破（晋升 / 渡劫）**：打项目积累「资历」，消耗资历晋升层数（全局倍率 ×1.12/层）；满 9 层可**渡劫**突破大境界（全局 ×3）。九大境界：练气期(摆摊创业) → 筑基期(注册公司) → 金丹期(天使轮) → 元婴期(A轮) → 化神期(B轮) → 炼虚期(C轮) → 合体期(独角兽) → 大乘期(上市辅导) → **渡劫飞升(敲钟上市)**。
- **二次创业（转生）**：进度停滞时重开本局，按累计营收换取永久货币「声望/股权」，投入商业心法（全员产出/攻击、聘请折扣、启动资金、离线上限）永久变强，开启更强的新纪元。

## 运行

纯单文件、零依赖、免安装、免编译 —— **直接用浏览器打开 `index.html` 即可游玩**。进度自动保存在本地浏览器（localStorage），设置页可导出/导入存档。

## 技术

- 单个 `index.html`，内联 CSS + 原生 JavaScript，`requestAnimationFrame` 驱动主循环。
- 国潮 / 水墨修仙视觉：墨黑宣纸底、描金标题印章、玉青点缀、朱砂血条，纯 CSS 无外部资源。
- 大数字中文单位格式化（万 / 亿 / 兆 / 京 / 垓…）。
