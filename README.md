# 孤岛方舟 · 生存进化 🏝️

一款浏览器上的 **2D 俯视角生存游戏**，玩法灵感取自《方舟：生存进化》。你在一座荒岛醒来，身无长物——**采集、制作、建造、驯服**，活过每一个夜晚，成为荒岛的主人。

> 采集资源 → 合成工具武器 → 建造基地 → 驯服同伴 → 昼夜求生

## 玩法

- **生存数值**：体力(HP)、饥饿、口渴、耐力四条状态条随时间变化。饥饿/口渴归零后持续掉血；靠近水源喝水、进食可恢复，数值充足时缓慢回血。
- **采集资源**：靠近 🌳树木 / 🌲松树 / 🪨岩石 / ⛰️矿脉 / 🌿草丛 / 🫐浆果丛，按「采集」收集木材、石头、纤维、浆果、金属。节点会随时间自动再生。
- **合成制作**：用资源合成 🪓石斧、⛏️石镐（对口工具采集速度 ×3）、🗡️长矛、🔦火把、⚔️金属剑，以及靠 🔥营火 烹饪 🍖熟肉。
- **建造基地**：搭建 🧱木墙 / 🚪木门 挡住野兽，🔥营火烹饪照明，🕯️火把架固定照明，🛏️床设为重生点，📦储物箱。
- **驯服同伴**：反复用 🫐浆果喂食 🐇野兔 / 🦌鹿 / 🐗野猪 即可驯服，同伴会跟随你并自动攻击野兽。
- **昼夜循环**：一整天约 8 分钟。夜晚变暗、野兽（🐺恶狼、🐻棕熊）更多更强，需要营火照明与围墙防守。
- **战斗与死亡**：装备武器攻击可击退野兽；倒下后在床（或岛中心）重生，会损失部分资源。

## 操作

| | 电脑 | 手机 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 左侧摇杆 |
| 采集 / 攻击 | `空格` | 右下「采集」按钮 |
| 进食 | `E` | 🍖 按钮 |
| 喝水 | `Q` | 💧 按钮 |
| 切换装备 | `1`~`4` | 底部快捷栏 |
| 背包/合成/建造/同伴/设置 | 右上菜单按钮 | 右上菜单按钮 |

## 运行

纯单文件、零依赖、免安装、免编译 —— **直接用浏览器打开 `index.html` 即可游玩**。进度自动保存在本地浏览器（localStorage），设置页可导出/导入存档。

## 技术

- 单个 `index.html`，内联 CSS + 原生 JavaScript，Canvas 2D 渲染，`requestAnimationFrame` 驱动主循环。
- 俯视角 tile 地图，实体按 y 轴排序实现伪 3D 叠放；动态昼夜光照（`destination-out` 挖光 + `lighter` 暖色叠加）。
- 采集/合成/建造/驯服/战斗/存档等系统全部内置，emoji 作为美术资源，无任何外部依赖。
